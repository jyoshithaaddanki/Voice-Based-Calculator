
# 🎙️ Voice-Based Calculator

## 📌 Project Description

**Voice-Based Calculator** is a web application that allows users to perform basic mathematical calculations using their voice. The application uses speech recognition to understand voice commands and displays the calculated result.

## 🎯 Features

* 🎤 Voice-based input
* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Supports basic calculations
* 🧮 Displays calculation results
* 💻 Simple and user-friendly interface
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** – Creates the calculator structure
* **CSS3** – Provides styling and responsive design
* **JavaScript** – Handles calculations and voice recognition
* **Web Speech API** – Converts voice commands into text

## 🚀 How to Run

### Step 1: Clone the Project

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open in VS Code

Open the **Voice-Based-Calculator** folder in Visual Studio Code.

### Step 3: Run the Project

Open `index.html` using **Live Server**.

### Step 4: Allow Microphone Access

When the browser asks for microphone permission, click **Allow**.

### Step 5: Give a Voice Command

For example, say:

```text
10 plus 5
```

The calculator will display:

```text
15
```

Other examples:

```text
20 minus 8
6 multiplied by 4
20 divided by 5
```

## 🎯 Objective

The objective of this project is to create an easy-to-use calculator that performs mathematical operations through **voice commands**, reducing the need for manual typing.
