# Voice Based Calculator

## 📌 Project Description

Voice Based Calculator is a simple Python application that performs mathematical calculations using voice commands. The application captures the user's speech through a microphone, converts it into text using Google Speech Recognition, and calculates the result.

## ✨ Features

* 🎤 Voice input
* 🧮 Performs mathematical calculations
* 📝 Converts speech into text
* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🐍 Simple Python project

## 🛠️ Technologies Used

* Python
* SpeechRecognition
* PyAudio
* Google Speech Recognition

## ⚙️ Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the following command:

```bash
python voice_calculator.py
```

Speak a calculation when prompted.

### Example

```text
🎤 Say a calculation...
25 plus 10

Recognized: 25 plus 10
✅ Result: 35
```

## 🎯 Objective

The objective of this project is to demonstrate the use of speech recognition and Python programming to create a voice-controlled calculator.
